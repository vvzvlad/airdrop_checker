# This file has always been a complete closure — even transitive names like certifi and
# idna are pinned above — and leaving these five to float would have quietly ended
# that: two builds of the same commit could produce different images, and a future
# pydantic release incompatible with pydantic-settings 2.7.0, or one that drops python
